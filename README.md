# CheckMMG — PWA

Application web installable (iPhone / Android) pour notifier par SMS l'ouverture et la fermeture d'une Maison Médicale de Garde.
Usage interne APC 22 — Antenne de Lannion. Éditeur : HAWKUS CORP.

Sur iPhone : ouvrir l'adresse dans Safari → Partager → « Sur l'écran d'accueil ».
Les données restent dans le téléphone ; aucun suivi, aucun compte.
